# Security Policy

## Supported Versions

Varc is under active development. This repository is a public feedback hub;
security reports for Varc and this repository are handled against the latest
publicly available build.

| Version | Supported |
| --- | --- |
| Latest publicly available build | :white_check_mark: |
| Older builds | :x: |
| Development builds | :warning: Best effort |

If you are unsure which version is affected, report it anyway and include the
exact Varc version and operating system.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Use GitHub's private vulnerability reporting channel:

[Report a vulnerability privately](https://github.com/varcdev/varcapp/security/advisories)

Please include:

- the affected Varc version and operating system
- the security impact
- steps to reproduce or a minimal proof of concept
- relevant logs or screenshots with secrets and private data removed
- whether the issue affects the current publicly available build

Never include passwords, access tokens, private keys, full connection strings,
database contents, or customer data. If a secret has already been exposed,
revoke or rotate it immediately.

There is no guaranteed response-time SLA yet. We will acknowledge reports as
soon as reasonably possible, keep the conversation private while
investigating, and provide updates when the report is accepted, needs more
information, or is declined. When appropriate, accepted reports will be
coordinated with a fix and a public advisory after a fix is available.
