## Welcome

Varc is a developer-focused desktop client for Redis and Valkey. This
repository is the public place to tell us what is working, what is not, and
what would make Varc more useful.

## Choose a path

| What happened? | Where to go |
| --- | --- |
| Something crashed, broke, or behaved unexpectedly | [Report a bug](https://github.com/varcdev/varcapp/issues/new?template=bug_report.yml) |
| You have an idea or workflow that could be better | [Request a feature](https://github.com/varcdev/varcapp/issues/new?template=feature_request.yml) |
| You have more information about an existing report | [Find the issue](https://github.com/varcdev/varcapp/issues) and add a comment |

## What makes a great bug report?

The more concrete the report, the faster it can be investigated. Please
include:

1. The Varc version.
2. Your operating system.
3. The shortest steps that reproduce the problem.
4. What you expected to happen.
5. What happened instead, including any visible error message.

Screenshots and redacted logs are welcome when they make the problem easier to
understand.

## Keep reports safe

> Please remove passwords, access tokens, private keys, full connection URLs,
> customer data, and other sensitive information before posting logs or
> screenshots.
